Which flow spent this transaction?

The ServiceNow® platform records every Integration Hub transaction and every flow run. Nothing joins the two, so an admin can't see which flow spent a transaction, or whether it bought anything.

What I tested

On a free developer instance (Australia release) I built six small flows, each showing one pattern: no call, one call, a call before a check, a failing call, a call whose result is used, and a flow that polls every 5 minutes. I wrote down every prediction before the flows ran, then checked it against the platform's own usage table.

Ledger match 8 of 8 transactions Calls linked to their run 22 of 22 Polling flow 12 of 12 predicted

What I found

  1. The two halves sit on separate tabs. The FDIH Dashboard shows transactions by action on one tab and flow runs on another. No run shows what it used. The usage table counts per action per month, so two flows sharing one action are a single line.
  2. A failed call looks healthy. Two calls that returned HTTP 500 were both counted as transactions. Their runs were marked Complete, and the dashboard header showed 0 errored runs for those 24 hours.
  3. Some calls buy nothing, and nothing says so. A flow that calls out before checking whether it needs to, or polls when nothing has changed, pays for every call. One flow polling every 5 minutes makes about 8,640 calls in 30 days.

The data for all of this exists on the platform, and admins do find workarounds. What the usual workarounds miss is the outcome of each call, and the history: flow runs are purged after about 30 days, so the evidence is gone by renewal.

What the tool shows

Callmeter is a small open-source, read-only tool that joins the call log, the flow runs and the record history through the REST Table API. On the test lab:

The lab is built to show these patterns, so its share of waste says nothing about real instances. That's what I want to learn next.

Where I'd value your view

  • Do customers ask which flows are using their transactions, and what do they do today?
  • Is "calls that bought nothing" a useful way to frame it, or is there a better measure?
  • What am I missing about how integration-heavy customers run flows at scale?
